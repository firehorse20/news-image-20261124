One image summing up the world's news of Tuesday, 24 November 2026 — a dense
front page with **39 stories across 12 regions**, a UTC time bar and a
schematic world map with dots. Rendered from HTML/CSS in headless Chromium;
`main.ts` (Node 22, stdlib only) copies `entry.png` to the output directory
and verifies the copy by size and sha256. No network at run time; two runs
are byte-identical.

v2 replaces v1 (which ranked 4533 of 7302 in round 1): same dense format,
but built from the full day's news — including the afternoon and evening
stories v1 missed — and set in larger, higher-contrast type so every
headline reads at judge resolution. Fewer words per story, no grey-on-grey.
